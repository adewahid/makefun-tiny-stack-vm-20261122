# Tiny Stack VM

A tiny stack virtual machine for make.fun's "Build a tiny stack virtual machine, 22 November 2026" bounty. One program answers all 40 instances of a drawn set: it runs each bytecode program of make.fun's tiny stack ISA and writes exactly the bytes it outputs and the exit code it ends with.
